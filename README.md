# 认识涡振 · 桥梁抗风交互课堂

在线学习：[认识涡振](https://syzhaoln-stack.github.io/bridge-viv-lab/)  
另一部分：[减振与控制](https://syzhaoln-stack.github.io/bridge-mitigation-lab/)

本站默认进入“认识涡振”，保留页内两部分切换。适配电脑和手机，包含实时流场、结构运动、对比时程、频谱与课堂记录导出。

## 运行

这是无外部运行依赖的静态网页。GitHub Pages 从 `main` 分支根目录发布。下载后可在本目录运行 `python -m http.server 8000`，再打开 `http://localhost:8000/`；请保留所有配套文件，Worker 需要通过网页服务器加载。

## 模型范围

- 涡振部分使用二维低 Re 流场与竖向单自由度双向耦合；不是实桥高 Re 湍流、扭转或三维涡振预测。
- 标准与快速网格均为教学离散，快速网格只能作定性预览。频谱来自实际有限时窗；同步候选区间不是已标定的实桥锁定边界。
- 气动措施、梁有限元、空间索系和主动控制分别采用页面注明的假设，不能将不同模型的结果直接混作工程验算。
- 虎门大桥水马案例用于理解断面变化，当前模型没有复现实桥风场与振幅。

公式、来源和进一步限制见 [模型与依据](evidence.html)。
